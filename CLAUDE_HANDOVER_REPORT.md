## 2. Результаты локального тестирования

### 2.1. API & Backend Тесты (`npm test` — Node.js Test Runner)
- **Результат:** 8 тест-сьютов, 34 теста, **34 passed, 0 failed, 0 skipped** (время выполнения: ~2.1 сек).
- **Схема изоляции:** Каждый тест-сьют запускается на отдельном порту со своей изолированной SQLite базой:
  - `tests/api.test.js` (порт 4001): базовые сквозные сценарии (Student, Staff, Admin, отбор, FormData).
  - `tests/auth_logic.test.js` (порт 4005): 13 сценариев логина, нормализации номеров, валидации паролей.
  - `tests/privacy_phone.test.js` (порт 4007): 17 проверок согласия 152-ФЗ, форматов телефонов, защиты API.
  - `tests/reliability.test.js` (порт 4011): healthcheck, создание/ротация резервных копий SQLite, единый источник направлений.
  - `tests/rbac.test.js` (порт 4021, **новый**): блокировка неавторизованных (401), запрет Student к `/api/audit` и `/api/recruitment/tracks` (403), доступ Admin (200).
  - `tests/leaderboard_notifications.test.js` (порт 4022, **новый**): проверка структуры ответа `/api/leaderboard` и `/api/notifications` (объект `{ notifications, unreadCount }`).
  - `tests/public_recruitment.test.js` (порт 4023, **новый**): отдача направлений отбора, 404 на несуществующие, отклонение неполных заявок с 4xx кодом.
  - `tests/bad_input.test.js` (порт 4024, **новый**): устойчивость к битому JSON (400), пустому body (400), несуществующим роутам (404 JSON).

### 2.4. Сквозные тесты интерфейса (`npx playwright test`)
- **Результат:** 5 passed, 3 failed.
- **Успешные сценарии:**
  - `Guest access` — главная страница и портал отбора доступны гостю.
  - `ADMIN flow` — пользователи и аудит открываются.
  - `Navigation Stability (STUDENT)` — быстрые переходы между страницами без крашей.
  - `Navigation Stability (STAFF)` — стабильность переходов сотрудника.
  - `Browser Back/Forward/Reload` — сохранение состояния при истории браузера.
- **Причины падения 3 тестов (рассинхрон устаревшего теста со свежим UI):**
  1. `STUDENT flow` ожидал текст `Мои текущие назначения`. На свежем дашборде этот блок рендерится условно (`data.myAssignments?.length > 0`), в сиде чистой тестовой базы у студента 0 активных назначений.
  2. `STAFF flow` ожидал текст `Наборы в медиацентр`. В актуальном дизайне заголовок страницы `RecruitmentReview.jsx` называется `Заявки на отбор`.
  3. `Two browser tabs` упал по таймауту ожидания перенаправления на `/dashboard`.

### 2.5. Аудит зависимостей (`npm audit`)
- Обнаружено 3 уязвимости в dev-зависимостях:
  - `shell-quote` (critical, CVE via `concurrently`).
  - `source-map-js` (high, DoS через смещения source-map).
- На продакшн-рантайм (Express, bcryptjs, better-sqlite3) уязвимости не влияют, так как находятся в инструментах разработки (`concurrently`). Рекомендуется обновить через `npm audit fix` или точечный апдейт `concurrently` / `overrides`.

- Контроль целостности: `PRAGMA foreign_keys = ON`.
