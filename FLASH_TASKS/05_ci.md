# ЗАДАЧА 5. CI в GitHub Actions

Перед началом прочитай `00_RULES.md`.

Создай ТОЛЬКО один новый файл `.github/workflows/ci.yml`. Больше ничего не меняй.

Содержимое (скопируй как есть):

```yaml
name: CI

on:
  pull_request:
  push:
    branches: [main, dev]

jobs:
  check:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 22
          cache: npm
      - run: npm ci
      - run: npx eslint . --quiet
      - run: npm run build
      - run: npm test
        env:
          NODE_ENV: test
          SESSION_SECRET: ci-test-secret
```

Проверь, что `package-lock.json` существует в корне (он есть). Локально CI запустить нельзя — просто убедись, что YAML валиден
(отступы пробелами, без табов) и что те же три команды локально проходят.

Коммит: `ci: add GitHub Actions workflow (lint, build, test)`
