# ЗАДАЧА 1. Чистка предупреждений eslint (безопасная)

Перед началом прочитай `00_RULES.md`.

Цель: уменьшить число warning (сейчас ~140) удалением ТОЛЬКО неиспользуемого мусора.

## Что делать
1. Выполни `npx eslint . -f unix` и посмотри список предупреждений.
2. Разрешено исправлять ТОЛЬКО правила `no-unused-vars` и только так:
   - удалить неиспользуемый `import` / неиспользуемую именованную часть импорта;
   - удалить неиспользуемую локальную переменную, ЕСЛИ её инициализатор не имеет побочных эффектов (литерал, чистая деструктуризация);
   - если переменная нужна по смыслу (например `catch (e)` или параметр коллбэка) — переименуй в `_имя` или удали `(e)` из `catch`.
3. Файлы в `server/` — трогай ТОЛЬКО удаление неиспользуемых импортов (строки `import ...`). Не трогай тело функций.
4. Файлы в `tests/` — не трогай вообще.
5. Другие правила (`react-hooks/*`, `no-undef` и т.д.) — НЕ исправляй, они могут менять поведение.

## Критерий готовности
- ошибок eslint по-прежнему 0;
- warning стало меньше (запиши в PROGRESS «было N → стало M»);
- `npm run build` и `npm test` зелёные.
Коммит: `chore(lint): remove unused imports and variables`
